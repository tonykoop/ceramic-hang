# Ceramic Hang CNC / Digital Fabrication Setup Sheet

## Scope

This is a pre-CAM setup plan for masters and shop fixtures. It is not G-code.

## Datums

- Primary datum: shell centerline.
- Secondary datum: rim plane.
- Tertiary datum: gu center and tone-field angular index.

## Digital Fabrication Operations

1. Print upper shell master oversized by measured shrinkage.
2. Print lower shell master oversized by measured shrinkage.
3. Optionally cut cottle templates and drying cradle profiles.

## Release Checks

- Shrinkage factor is measured, not assumed.
- Master dimensions match scaled CAD.
- Segment seams are filled and sealed.
- Mold split has a clean pull direction.
- Drying cradle supports the rim/shell without point loading.
